# Поиск Corepolis в Яндексе

Публичный адрес: https://deenfoool.github.io/Corepolis/
Карта сайта: https://deenfoool.github.io/Corepolis/sitemap.xml

На главной странице есть статическое описание игры, заголовок, canonical,
разрешающий meta robots, Open Graph и JSON-LD VideoGame. Каталог моделей
закрыт от индексации через noindex, follow. Карта сайта содержит только игру.

## Подключение Яндекс Вебмастера

1. Откройте https://webmaster.yandex.ru/ и добавьте точный публичный адрес игры.
2. Выберите подтверждение прав метатегом. Передайте выданный Яндексом тег
   разработчику, чтобы он добавил его в head главной страницы и опубликовал.
   Затем нажмите подтверждение в Вебмастере. Не используйте выдуманный токен.
3. В разделе «Индексирование → Файлы Sitemap» добавьте адрес карты сайта.
4. В разделе «Индексирование → Переобход страниц» отправьте главную страницу.
5. Следите за диагностикой, обходом робота и страницами в поиске.

Поиск сам решает, когда включить сайт в индекс и на какой позиции показать.
Метаданные и отправка адреса не гарантируют появление или первое место.

## GitHub Pages и robots.txt

Роботы запрашивают https://deenfoool.github.io/robots.txt — в корне домена.
Файл внутри /Corepolis/ не управляет обходом сайта, поэтому здесь он не создаётся.
Для текущей публикации используются метатеги страниц; Sitemap отправляется
через Вебмастер. Если в будущем меняется домен, обновите canonical, og:url,
абсолютные адреса изображений, JSON-LD и sitemap.xml вместе.

Официальная справка:
- https://yandex.ru/support/webmaster/ru/recommendations/indexing
- https://yandex.ru/support/webmaster/ru/controlling-robot/robots-txt
